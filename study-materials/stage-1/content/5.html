From idea to board: the Arduino IDE

The Arduino IDE is the path from idea to board. Choose the correct board and port before uploading. The IDE turns your sketch into instructions the board can run.

  1. Write — Create a sketch in the editor.
  2. Compile — Check for errors and build instructions.
  3. Upload — Send the compiled sketch through USB to the Arduino.
  4. Run — The board starts the new sketch.

Two ways to read: digital and analog

Digital asks a yes-or-no question; analog measures a range.

Digital: LOW or HIGH

Two clear states. Use digitalRead() to read and digitalWrite() to control. Switches and LEDs fit this yes-or-no model (open / closed).

Analog: a changing value

Measure a range from a sensor or potentiometer with analogRead(). Brightness, position, and light level can vary (less / more).

Setup and loop

Every Arduino sketch has a setup and a loop. One opening step prepares the board. Then one repeating step keeps the project alive.

setup()

Runs once when the board starts or resets.

loop()

Runs repeatedly while the board has power.

  • Read — Check inputs and signals.
  • Update — Make decisions and change outputs.

Pin behavior

pinMode() tells a pin how to behave. Choose whether the pin listens, drives, or listens with an internal pull-up resistor.

INPUT

The pin listens for an external signal, such as a switch.

OUTPUT

The pin drives a component, such as an LED.

INPUT_PULLUP

The pin listens with the Arduino’s internal pull-up resistor. Open = typically HIGH; connected to GND = LOW.

pinMode(7, INPUT_PULLUP);

Code shape

Code punctuation gives the sketch its shape. Comments explain intent; brackets show which instructions belong together.

//

Starts a single-line comment.

// read the switch

/* */

Wraps a multi-line comment.

/* setup notes */

( )

Holds a function’s inputs or conditions.

delay(1000);

{ }

Marks the beginning and end of a block.

void loop() { }

First project: blink the built-in LED

Use pin 13, set it as an output, then alternate HIGH and LOW inside loop(). A working sketch is a conversation between code and light.

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}
  • setup() prepares the pin once.
  • loop() repeats.
  • HIGH / LOW turns the LED on/off.

Installing the Arduino IDE

Step 1: Download the software

  1. Go to the official website: arduino.cc/en/software.
  2. Select the installer for your operating system (Windows, macOS, or Linux).
  3. Download the latest version of the Arduino IDE 2.x.

Step 2: Install the IDE

  1. Run the downloaded installer file.
  2. Follow the setup wizard prompts and accept the license agreement.
  3. Complete the installation and open the Arduino IDE.
Important

Ensure driver installation options (USB drivers) are checked during setup.

Step 3: Connect and select your board

  1. Plug your Arduino UNO into your computer using a USB cable.
  2. In the top toolbar of the IDE, click the Board dropdown.
  3. Select Arduino Uno from the list.
  4. Select the corresponding COM port (Windows) or /dev/cu.usbmodem (macOS).

Try, observe, change

Upload, observe, and debug one change at a time.

  1. Select Arduino UNO and the correct USB port.
  2. Compile before uploading so errors are easier to locate.
  3. Observe the LED and compare the result with the sketch.
  4. Check pin number, pinMode(), polarity, USB connection, and brackets.
  5. Change one thing, upload again, and observe what changed.

Small experiments turn code into understanding.
